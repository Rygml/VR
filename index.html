Setup (iPhone):
1. Install Sensor Logger (free, App Store) on your iPhone.
2. On your PC run: cd bridge && npm install && node server.js — note the IP shown.
3. In Sensor Logger → Push: enable, set URL to http://<PC_IP>:8765/data, interval 20 ms.
4. Enable sensor: Attitude (yaw / pitch / roll in radians).
5. Enter PC IP above and press Connect.
6. Tilt your iPhone — the Neovious surface rotates in sync via ZXY Euler matrix.

When sensor is disconnected: drag to rotate  ·  Red-cyan glasses for stereo effect
